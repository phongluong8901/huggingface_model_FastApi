# --- about
Dự án này xây dựng một hệ thống Machine Learning phục vụ bài toán Dự đoán chấp thuận thị thực lao động Mỹ (US Visa Approval Prediction).

Dựa trên dữ liệu hồ sơ xin visa (như loại công việc, mức lương, trình độ học vấn, kinh nghiệm, thông tin nhà tuyển dụng, v.v.), mô hình sẽ phân loại và dự đoán xem hồ sơ xin thị thực đó có được chấp thuận (Certified) hay bị từ chối (Denied) hay không.

Trọng tâm của dự án không chỉ nằm ở mô hình dự đoán mà còn ở khía cạnh MLOps, bao gồm:

Xây dựng pipeline dữ liệu và huấn luyện tự động.

Theo dõi thí nghiệm với MLflow.

Đóng gói ứng dụng bằng Docker.

Thiết lập tự động hóa CI/CD qua GitHub Actions.

Đưa mô hình lên mây (AWS ECR và AWS EC2) để triển khai thực tế dưới dạng dịch vụ web.
